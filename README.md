# Cache Memory Simulator

A Python-based project for learning and simulating cache memory concepts as part of a Computer Architecture Laboratory course.

## Project Status

The project is currently in its initial setup stage. The Python environment and GitHub repository have been configured successfully.

## Planned Features

- Simulate cache memory access operations
- Implement Direct-Mapped cache mapping
- Implement Fully Associative cache mapping
- Track cache hits and misses
- Calculate hit rate and miss rate
- Implement FIFO replacement policy
- Explore LRU replacement policy if time permits
- Test the simulator with sample memory access sequences
- Compare cache configurations and visualize results

## Technologies

- Python
- Git and GitHub
- Visual Studio Code
- Matplotlib (planned, if needed)

## Getting Started

### Prerequisites

- Python 3.13 or a compatible Python 3 version
- Git (optional, if you only want to download and run the project)

### Run the Current Program

Clone the repository, navigate to the project directory, and run:

```bash
python main.py
```

On Windows, you can also use:

```powershell
py main.py
```

The current program is an initial environment check. The cache simulation functionality has not been implemented yet.

## Project Goals

The goal is to build a simple, understandable, and testable cache simulator while learning the fundamentals of cache memory and software version control.
